# 갈현이룸태권도 상담 PPT — GPT 이미지 요청서 (9장 전체 요소)

## 사용 순서 (작업자용 · GPT에 보내지 마세요)

1. GPT 새 채팅에 **샘플 이미지(9장 합본)를 첨부**하고 **[STEP 0 마스터 프롬프트]**를 그대로 붙여넣습니다.
2. **[STEP 1 캐릭터 시트]**로 캐릭터 얼굴을 먼저 확정합니다. 마음에 들 때까지 여기서 수정하세요. 이후 모든 캐릭터가 이 시트를 기준으로 그려집니다.
3. **STEP 2(필수)** 블록을 **한 번에 하나씩** 순서대로 보냅니다. 한 번 요청할 때마다 이미지 1장입니다.
4. 받은 이미지는 **파일명 그대로** `galhyeon-taekwondo/assets/`에 넣으면 HTML 초안의 점선 자리에 자동으로 들어갑니다.
5. 배경이 흰색으로 나오면 이렇게 보내세요: `방금 이미지 배경만 투명 PNG로 다시 출력해줘. 그림은 절대 바꾸지 마.`

### 무엇을 GPT로 받고, 무엇이 이미 되어 있나

| 구분 | 요소 | 상태 |
|---|---|---|
| **필수 (GPT)** | 캐릭터 12장 + 노란 버스 1장 (C01~C13) | 이 문서 STEP 2 |
| 선택 (GPT) | 붓 터치 배경, 붓글씨 로고·문구, 아이콘 12개, 장식 | **초안에 샘플과 같은 모양의 벡터로 이미 들어가 있음** (PPT에서 색·모양 수정 가능). GPT 결과가 더 마음에 들 때만 STEP 3으로 받아서 교체 |

> 글자는 이미지에 넣지 않습니다. 제목, 설명, 금액, 시간표, 버스 옆면의 "갈현이룸태권도"는 모두 PPT 텍스트로 넣어서 의뢰인이 나중에 고칠 수 있게 합니다.

## [STEP 0 · 마스터 프롬프트] — 첫 메시지 (샘플 이미지 첨부와 함께)

```
지금부터 태권도장 상담용 PPT(16:9, 9장)에 들어갈 "이미지 소스"만 만들 거야.
첨부한 이미지는 완성 PPT 9장을 한 장에 모아 둔 디자인 샘플이야.
너는 이 샘플 속 캐릭터와 버스 그림을 PPT에 따로따로 배치할 수 있게 "개별 이미지"로 하나씩 다시 그려 주면 돼.
슬라이드 레이아웃, 글자, 표, 카드 박스, 아이콘, 배경은 내가 PPT에서 따로 만드니까 그리지 마.

[반드시 지킬 규칙 — 이후 모든 요청에 계속 적용]
1. 한 번 요청에 이미지 1장만 만든다. 내가 지정한 대상만 그리고 다른 요소를 덧붙이지 않는다.
2. 배경은 무조건 투명 PNG. 배경색 면, 카드, 테두리 박스, 액자, 바닥 그림자를 넣지 않는다.
   (내가 소품이나 바닥을 넣으라고 한 경우에만 그것만 그린다)
3. 이미지 안에 글자, 숫자, 로고, 워터마크, 서명을 절대 넣지 않는다.
4. 대상은 가운데에 크게 두고 사방에 약 6% 여백을 남긴다. 머리끝, 손끝, 발끝이 잘리지 않게 전신이 다 나오게 그린다.
5. 그림체, 의상, 포즈, 색감, 소품은 첨부 샘플과 최대한 똑같이 맞춘다.
   단, 얼굴은 샘플을 그대로 복사하지 말고, 다음 요청의 "캐릭터 시트"에서 정한 오리지널 얼굴로 그린다.
   캐릭터 시트가 확정되면 이후 모든 캐릭터는 시트와 같은 얼굴, 헤어, 비율로 그린다.
6. 그림체(샘플과 동일):
   - 한국 아동 교육용 귀여운 치비 캐릭터, 약 2.5등신, 큰 머리, 큰 검은 눈동자에 흰 하이라이트, 활짝 웃는 입, 분홍 볼 터치
   - 진한 갈색~검정의 깔끔하고 일정한 굵은 외곽선
   - 셀 셰이딩 1단계 + 약한 하이라이트. 실사 질감, 3D 렌더, 과한 그라데이션 금지
   - 밝고 깨끗한 색감
7. 도복(샘플과 동일): 흰색 태권도 도복, 깃(옷깃)은 빨강(안쪽에 검정 줄), 맨발.
   띠 색은 요청마다 따로 지정한다.
8. 출력 크기: "세로"는 1024×1536, "가로"는 1536×1024, "정사각"은 1024×1024.

이해했으면 그림은 아직 그리지 말고 "준비 완료"라고만 답해줘.
```

## [STEP 1 · 캐릭터 시트] — 얼굴 확정 (가로, 흰 배경)

```
[C00 캐릭터 시트] 가로 1536×1024, 이번만 배경은 흰색.

이후 모든 이미지에 쓸 오리지널 캐릭터 2명의 기준 시트를 만들어줘.
그림체, 의상, 비율은 첨부 샘플과 똑같이, 얼굴과 헤어 디테일만 새로 디자인해.

- 남자아이: 7~8세, 갈색의 풍성하고 끝이 삐죽삐죽 뻗친 짧은 머리(앞머리가 이마를 덮음), 큰 검은 눈, 활짝 웃는 입, 분홍 볼.
- 여자아이: 6~7세, 짙은 갈색 머리를 양쪽 아래로 묶은 양갈래, 앞머리, 큰 눈, 밝은 미소, 분홍 볼.
- 둘 다 흰 도복, 빨간 깃, 맨발, 2.5등신. 시트에서는 남아는 검정 띠, 여아는 보라 띠.

구성: 남자아이 정면 / 3/4 측면 / 뒷모습, 여자아이 정면 / 3/4 측면 / 뒷모습 — 총 6개.
모두 차렷 자세, 같은 크기, 겹치지 않게 간격을 넉넉히. 글자나 이름표는 넣지 마.
```

## [STEP 2 · 필수 에셋] — 하나씩 순서대로

### C01 — 표지 캐릭터 (세로)
```
[C01_cover_kick] 세로 1024×1536, 투명 배경.
샘플 1장(표지) 오른쪽 캐릭터와 같은 포즈: 남자아이가 오른쪽 다리를 머리 위까지 곧게 뻗어 올린 앞올려차기.
- 차는 다리는 화면 왼쪽 위를 향해 수직에 가깝게 올라가고, 맨발 발바닥이 보이게.
- 몸은 3/4 측면(화면 왼쪽을 향함), 얼굴은 정면 쪽을 보며 입을 크게 벌려 활짝 웃음.
- 왼손 주먹은 가슴 앞 겨루기 자세, 디딤발은 땅을 단단히 딛음.
- 띠: 빨간 띠. 깃: 빨강.
- 전신, 발끝까지. 배경, 그림자, 효과선 없음.
```

```

- 매트: 파란색(#3A7BE6) 직사각형, 약간 두께감. 매트가 그림 하단 전체 폭을 차지.
- 띠: 검정. 매트 외 배경 없음.
```

## 문제가 생겼을 때 보낼 문장 (복붙용)

- 얼굴이 달라졌을 때
  `얼굴과 헤어가 C00 캐릭터 시트와 달라. 시트의 얼굴·머리·비율을 그대로 유지하고 포즈만 이번 요청대로 다시 그려줘.`
- 샘플과 포즈나 소품이 다를 때
  `첨부 샘플 ○장 ○○ 그림과 포즈가 달라. 샘플처럼 (구체적으로: 예) 다리를 머리 위까지 곧게) 다시 그려줘.`
- 글자가 들어갔을 때
  `이미지 안의 글자와 숫자를 모두 지우고 다시 출력해줘. 그림은 그대로 유지.`
- 몸이 잘렸을 때
  `캐릭터가 잘렸어. 85% 크기로 줄여서 머리끝·손끝·발끝이 모두 보이게 다시 출력해줘.`
- 그림체가 달라졌을 때
  `앞 이미지들과 그림체가 달라. 같은 선 두께, 같은 셀 셰이딩, 같은 색감으로 다시 그려줘.`
