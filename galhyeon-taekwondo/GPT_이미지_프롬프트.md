# 갈현이룸태권도 상담 PPT — GPT 이미지 요청서 (9장 전체 요소)

## 사용 순서 (작업자용 · GPT에 보내지 마세요)

1. GPT 새 채팅에 **샘플 이미지(9장 합본)를 첨부**하고, 아래 **[STEP 0 · 마스터 프롬프트]**를 그대로 붙여넣습니다.
2. **[STEP 1 · 캐릭터 시트]**를 보내 캐릭터를 먼저 확정합니다. 마음에 들 때까지 여기서 수정하세요. (이후 모든 캐릭터가 이 시트를 기준으로 그려집니다.)
3. 그다음 **STEP 2 ~ STEP 5** 블록을 **한 번에 하나씩** 순서대로 보냅니다. 한 번 요청 = 이미지 1장입니다.
4. 받은 이미지는 아래 **파일명 그대로** 저장해 `galhyeon-taekwondo/assets/` 폴더에 넣으면 HTML 초안에 자동으로 들어갑니다.
   - 아이콘 묶음(I-SHEET-A, I-SHEET-B, D-SHEET)은 한 장으로 받아서 넘겨주면 제가 잘라서 개별 파일로 넣겠습니다.
5. 투명 배경이 아니라 흰 배경으로 나오면: "방금 이미지 배경만 투명(PNG)으로 다시 출력해줘. 그림은 절대 바꾸지 마." 라고 보내세요.

> 왜 글자는 안 넣나요? → 슬라이드의 모든 텍스트(제목, 설명, 금액, 시간표)는 의뢰인이 나중에 고칠 수 있게 **PPT 텍스트로** 넣습니다. 이미지에 글자가 들어가면 수정이 불가능하므로, 붓글씨 로고(A02)와 마무리 문구(A03)를 빼고는 **이미지 안에 글자 0개**가 원칙입니다.

## [STEP 0 · 마스터 프롬프트] — 첫 메시지 (샘플 이미지 첨부와 함께)

```
지금부터 태권도장 상담용 PPT(16:9, 9장)에 들어갈 "이미지 소스"만 만들 거야.
첨부한 이미지는 완성 PPT 9장을 한 장에 모아 둔 디자인 샘플이야.
너는 이 샘플에 있는 그림 요소(캐릭터, 아이콘, 버스, 붓 터치 배경, 붓글씨 로고)를
PPT에 따로따로 배치할 수 있도록 "개별 이미지"로 하나씩 만들어 주면 돼.
슬라이드 전체(레이아웃·텍스트·표·카드 박스)는 내가 PPT에서 직접 만들 거라 필요 없어.

[반드시 지킬 규칙 — 이후 모든 요청에 계속 적용]
1. 한 번 요청에 이미지 1장만 만든다. 내가 지정한 대상만 그리고, 다른 요소를 덧붙이지 않는다.
2. 배경은 내가 "흰색"이라고 하지 않는 한 무조건 투명 배경 PNG로 출력한다.
   바닥 그림자, 배경 색면, 테두리 박스, 액자, 카드 배경을 넣지 않는다.
3. 이미지 안에 글자·숫자·로고·워터마크·서명을 절대 넣지 않는다.
   (붓글씨 로고와 붓글씨 문구 요청 2개만 예외 — 그때 내가 따로 말할게)
4. 대상은 화면 가운데에 크게, 사방에 여백을 약 8% 남기고, 몸이나 소품이 잘리지 않게 전체가 다 나오게 그린다.
5. 캐릭터는 샘플의 "그림체와 분위기"만 참고하고, 샘플 캐릭터를 똑같이 복제하지 않는다.
   (샘플 캐릭터는 저작권이 있어서, 비슷한 톤의 오리지널 캐릭터가 필요해)
   다음 요청에서 만들 "캐릭터 시트"가 확정되면, 이후 모든 캐릭터는 그 시트와 완전히 같은 얼굴·헤어·의상·비율로 그린다.
6. 모든 이미지의 그림체를 통일한다:
   - 한국 아동 교육용 귀여운 치비(SD) 캐릭터 일러스트, 2.5등신, 큰 머리와 큰 눈, 밝게 웃는 얼굴, 볼 터치
   - 진한 갈색/네이비 계열의 깔끔하고 일정한 외곽선(선 두께 일정)
   - 부드러운 셀 셰이딩 1단계 + 약한 하이라이트, 과한 그라데이션·실사 질감 금지
   - 밝고 깨끗한 색감 (흰색 도복, 빨강 #E5352F, 네이비 #1B2A5E, 노랑 #F6B91C, 초록 #36B36A, 파랑 #1F63D6, 파스텔 핑크·하늘·연두·보라)
7. 도복 규칙: 흰색 태권도 도복, 깃(옷깃)은 검정 테두리, 띠는 빨강-검정 반반의 품띠(어린이 유단자 띠), 맨발.
8. 출력 크기: 내가 "세로"라고 하면 1024×1536, "가로"라고 하면 1536×1024, "정사각"이라고 하면 1024×1024.

이해했으면 그림은 아직 그리지 말고 "준비 완료"라고만 답해줘.
```

## [STEP 1 · 캐릭터 시트] — 캐릭터 확정 (가로, 흰 배경)

```
[C00 캐릭터 시트] 가로 1536×1024, 배경은 흰색(이것만 예외).

이후 모든 이미지에 쓸 오리지널 캐릭터 2명을 확정하는 기준 시트를 만들어줘.
첨부 샘플의 그림체·분위기만 참고하고, 얼굴과 헤어는 새롭게 디자인해.

- 남자아이 "이룸이": 7~8세, 갈색의 풍성하고 살짝 뻗친 짧은 머리, 큰 갈색 눈, 활짝 웃는 입, 볼 터치.
- 여자아이 "가온이": 6~7세, 짙은 갈색 머리를 양쪽으로 묶은 양갈래(작은 빨간 고무줄), 큰 눈, 밝은 미소, 볼 터치.
- 둘 다: 흰색 태권도 도복, 검정 깃 테두리, 빨강-검정 품띠, 맨발, 2.5등신 치비 비율.

구성: 남자아이 정면 / 3/4 측면 / 뒷모습, 여자아이 정면 / 3/4 측면 / 뒷모습 — 총 6개 포즈를 한 줄 또는 두 줄로,
모두 차렷 자세, 같은 크기, 서로 겹치지 않게 간격 넉넉히. 글자·이름표 넣지 마.
```

샘플 1장(표지)과 9장(마무리)의 배경처럼, 흰 바탕 위에 태극기 느낌의 거친 붓 터치 줄무늬를 그려줘.

  약 30도 기울기(왼쪽 아래 → 오른쪽 위 방향)로 화면 밖으로 뻗어 나가게.
- 왼쪽 아래 모서리: 빨강 굵은 붓 터치 1줄 + 네이비 굵은 붓 터치 1줄이 같은 30도 기울기로.
- 붓 끝은 마른 붓처럼 갈라지고 거칠게(드라이 브러시 질감), 속도감 있게.

## 문제가 생겼을 때 보낼 문장 (복붙용)

- 캐릭터 얼굴이 달라졌을 때
  `캐릭터 얼굴과 헤어가 C00 캐릭터 시트와 달라. 시트의 얼굴·머리·도복·띠·비율을 그대로 유지하고 포즈만 이번 요청대로 다시 그려줘.`
- 글자가 들어갔을 때
  `이미지 안의 모든 글자와 숫자를 지우고 다시 출력해줘. 그림은 그대로 유지.`
- 몸이 잘렸을 때
  `캐릭터가 잘렸어. 크기를 85%로 줄여서 전신(발끝·손끝·머리 끝)이 모두 보이게 다시 출력해줘.`
- 붓글씨 오타가 났을 때
  `글자가 틀렸어. 정확히 "갈현이룸태권도"(갈·현·이·룸·태·권·도) 일곱 글자로, 같은 붓 스타일로 다시 써줘.`
- 그림체가 달라졌을 때
  `앞에서 만든 이미지들과 그림체가 달라. 같은 선 두께, 같은 셀 셰이딩, 같은 색감으로 다시 그려줘.`
