# 갈현이룸태권도 상담 PPT (9장)

- `index.html` — 9장 HTML 초안 (1600×900, 16:9). 브라우저로 열면 확인, "PDF로 저장" 버튼으로 PDF 출력.
- `GPT_이미지_프롬프트.md` — GPT 이미지 요청서 (마스터 프롬프트 → 캐릭터 시트 → 에셋별 프롬프트).
- `assets/` — GPT로 받은 이미지를 요청서의 파일명 그대로 넣는 곳. 없는 이미지는 초안에서 점선 자리표시로 보임.
- `fonts/` — 샘플과 맞춘 폰트.

## 폰트 (샘플 대조 후 선정)

| 용도 | 폰트 | 비고 |
|---|---|---|
| 슬라이드 제목, 카드 제목, 번호 배지, 금액 | 여기어때 잘난체 | 샘플 제목과 거의 동일 |
| 표지 손글씨 문구 | 유토이미지 손글씨 | 두꺼운 마커 손글씨 계열 중 가장 가까움 |
| 본문, 설명, 시간표 | Pretendard | |
| 영문 "GALHYEON IRUM TAEKWONDO" | Montserrat ExtraBold | 자간 넓게 |
| 붓글씨 로고 / "배우고 성장하고 이루다" | GPT 이미지 (A02, A03) | 무료 폰트 중 샘플 붓글씨와 맞는 것이 없어 이미지로 처리 |

PPT 납품 시: 의뢰인 PC에 위 폰트가 없으면 깨지므로 **파일 › 옵션 › 저장 › "파일의 글꼴 포함"**을 켜고 저장하거나, 폰트 파일을 같이 전달.
