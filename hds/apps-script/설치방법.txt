[먼저 기능 확인] HDS-안전장부-미리보기.html
  - 압축을 푼 뒤 PC에서 더블클릭(크롬·엣지). 인터넷·설치 필요 없음.
  - [예시로 둘러보기] → 모든 화면·양식·사진 첨부·조치·엑셀을 바로 확인할 수 있습니다.
  - 사업장·인원 메뉴의 [사업장 화면 보기]로 사업장 담당자 화면도 확인합니다.
  - 미리보기의 기록은 그 PC 브라우저에만 저장됩니다.

HDS 안전장부 — 구글 앱스 스크립트 설치 방법 (10분)

1. https://script.google.com 접속 → [새 프로젝트]
2. 왼쪽 Code.gs 를 열고 안의 내용을 전부 지운 뒤, 이 폴더의 Code.gs 내용을 붙여넣기
3. 왼쪽 [파일 +] → [HTML] → 이름에 Index 입력(.html 은 자동) → 내용 전부 지우고 Index.html 내용 붙여넣기
4. 왼쪽 [파일 +] → [HTML] → 이름에 Forms 입력 → 내용 전부 지우고 Forms.html 내용 붙여넣기
5. 저장(Ctrl+S) → 오른쪽 위 [배포] → [새 배포] → 톱니바퀴에서 [웹 앱]
   - 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자 (사업장 직원이 구글 로그인 없이 쓰게 하려면)
   → [배포] → 권한 검토에서 본인 계정 선택 → [고급] → [안전하지 않은 페이지로 이동] → [허용]
6. 나온 '웹 앱 URL' 이 본사 링크입니다. 처음 열면 내 구글 드라이브에
   'HDS 안전장부 DB'(시트)와 'HDS 안전장부 첨부'(사진 폴더)가 자동으로 생깁니다.
7. 본사 링크에서 [본사용으로 시작] 또는 [예시로 둘러보기] → 사업장·인원에서 사업장 등록
   → [사업장 링크] 버튼으로 링크 복사(웹 앱 URL 끝에 ?site=S001) → 사업장 담당자에게 전달

수정 후 다시 올릴 때: [배포] → [배포 관리] → 연필 → 버전 [새 버전] → [배포] (URL 그대로 유지)

주의: 시안이라 링크를 아는 사람은 누구나 들어올 수 있습니다. 실제 운영 전에는 사업장 PIN 같은 접근 제한을 붙여야 합니다.
