이 시제품이 실제로는 어떻게 만들어지나

지금 보는 화면은 HTML 하나입니다. 실제 운영판은 같은 화면을 Apps Script에 붙여넣고, 저장하는 부분만 구글 시트로 바꿉니다. 화면 코드는 거의 그대로 씁니다.

① 화면 (Index.html)
  • 지금 이 페이지와 같은 HTML·CSS·JS
  • 사업장 QR 링크: …/exec?site=S001
  • 사진 압축, 서명 패드는 휴대폰 브라우저가 처리
② 서버 (Code.gs)
  • 기록 번호 발급(동시 제출에도 겹치지 않게 잠금)
  • 서버 시각 기록, 불량이면 조치 자동 생성
  • 매일 마감 판정·독촉 메일, 월간 PDF
③ 장부 (구글 시트)
  • 탭: 사업장, 인원, 일일점검, 조치, 사건
  • 사진·서명: 구글 드라이브 폴더, 시트에는 링크
  • 본사 화면은 시트를 읽어 그림

버튼 하나가 서버에서 하는 일 (Code.gs 예시)

// 현장에서 '제출'을 누르면 화면이 이 함수를 부릅니다
function saveInspection(data) {
  const lock = LockService.getScriptLock();   // 동시에 10명이 눌러도 번호가 겹치지 않게
  lock.waitLock(10000);
  try {
    const book = SpreadsheetApp.openById(BOOK_ID);
    const id = nextId('ID', data.site);       // ID-S001-261025-01
    const photos = savePhotos(data, id);      // 드라이브에 사진 저장 → 링크
    book.getSheetByName('일일점검').appendRow([
      id, data.site, new Date(), data.shift, data.person, JSON.stringify(data.items), photos.sign
    ]);
    data.items.filter(i => i.result === '주의' || i.result === '불량')
      .forEach(i => createAction(book, id, i, photos[i.code]));   // ACT-S001-2610-001
    return id;
  } finally {
    lock.releaseLock();
  }
}

// 화면(Index.html) 쪽은 한 줄입니다
