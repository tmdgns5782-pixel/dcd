도면 해석

3D 재구성

STEP 1

도면 이미지 입력

평면도·입면도 이미지만 입력

  • 평면도

    창·문의 평면 위치 X·Y

  • 입면도

    창·문이 놓인 높이 Z

입력 형식

  • 래스터 이미지 (픽셀 기반)

STEP 2

객체 인식

도면 속 벽·창문·문 인식

  • 평면도

    외벽 창·문을 동·서·남·북
    방향별로 정리

  • 입면도

    같은 층 창·문끼리 묶어
    층 높이 파악

핵심 기법

  • YOLO + SAHI (작은 객체 분할 추론)
  • DBSCAN 층별 클러스터링

STEP 3

대응 객체 매칭

평면도·입면도의 같은 객체끼리 짝짓기

  • 축척

    LMM(GPT-4o)이 축척을 읽어
    픽셀 → 실제 길이 환산1 px = 33.88 mm예시

  • 매칭

    X·Y + Z → 3차원 위치 확정

핵심 기법

  • LMM 기반 축척 보정
  • 헝가리안 알고리즘 (최적 1:1 매칭)

STEP 4

BIM 자동 생성

높이까지 갖춘 3D BIM 모델

  • 벽체

    골격선(스켈레톤)으로
    벽 중심선 추출

  • 창·문

    붙일 벽 결정(호스팅) 후
    Revit API로 BIM 생성

핵심 기법

  • 스켈레톤 기반 벽체 추출
  • Revit API
