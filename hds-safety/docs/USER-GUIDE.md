- [사업장 담당자용](#사업장-담당자용) — 링크로 들어가기, 오늘 할 일, 일일점검, 사고·아차 보고, 사진·서명, 반려 고치기, 조치 완료 보고

화면에 쓰는 말

| 말 | 뜻 |
|---|---|
| 작성중 | 저장만 하고 아직 내지 않은 기록 |
| 1단계 보고 | 단계가 있는 양식에서 앞 단계만 낸 기록. 본사에 보입니다 |
| 제출 | 사업장이 낸 기록. 본사 확인 대기 |
| 확인 | 본사가 확인한 기록. 잠겨서 고칠 수 없습니다 |
| 반려 | 본사가 돌려보낸 기록. 사유를 보고 고쳐 다시 냅니다 |
| 미제출 | 마감이 지났는데 내지 않음 |
| 기한경과 | 마감일이 지남 |

# 본사 담당자용

## 들어가기

1. 앱 주소(관리자가 알려 준 `…/exec` 주소)를 엽니다.
2. 아이디·비밀번호를 넣습니다. 같은 Workspace 도메인 계정이면 "구글 계정으로"를 눌러도 됩니다.
3. 처음 받은 비밀번호는 비밀번호 변경 메뉴에서 바꿉니다(관리자는 설정 화면). 8자 이상, 영문과 숫자를 함께 넣습니다.
4. 15분 안에 5번 틀리면 15분 동안 잠깁니다. 잊었으면 관리자에게 재설정을 요청합니다.

역할마다 할 수 있는 일이 다릅니다. 관리자는 전부, 담당은 사용자·설정을 뺀 전부, 열람은 읽기와 분석만 합니다.

## 종합 현황 보는 법

종합 현황은 "오늘 손봐야 할 사업장·건"을 보여 줍니다.

1. 제목 아래 회색 문장을 먼저 읽습니다. 지금 가장 눈여겨볼 사실 한 줄입니다.
2. 숫자 줄에서 확인 대기·미제출·기한경과 조치 같은 건수를 봅니다. 숫자 아래 문장은 지난 기간과의 비교입니다.
3. 오늘의 예외 목록을 위에서부터 처리합니다. 줄을 누르면 해당 기록·조치·사업장으로 갑니다.
4. 아래 작은 현황판은 이번 달 취합 현황입니다. 자세히 보려면 취합 현황으로 갑니다.

## 취합 현황판 보는 법

행은 사업장, 열은 양식(그 기간)입니다. 칸마다 기호 하나로 상태를 표시합니다.

| 기호 모양 | 뜻 |
|---|---|
| 네이비로 채운 사각 | 기한 내 제출 |
| 네이비 테두리 + 가운데 점 | 지연 제출(마감 뒤에 냄) |
| 네이비 채움 + 흰 체크 | 본사 확인 완료 |
| 반쯤 채운 사각 | 작성중 또는 1단계 보고 |
| 빨간 테두리 | 반려(사업장이 고치는 중) |
| 빨간 사선 무늬 | 기한경과 미제출 |
| 회색 테두리 빈칸 | 마감 전, 아직 안 냄 |
| 회색 대시 | 해당 없음(그 사업장 필수 양식이 아님) |

- 열 머리의 %는 그 양식의 회수율, 행 끝의 %는 그 사업장의 제출률입니다.
- 범례는 현황판 위에 같은 모양으로 작게 있습니다.

칸을 눌러 바로 처리합니다.

1. 낸 기록이 있는 칸을 누르면 그 기록이 열립니다.
2. 비어 있는 칸을 누르면 메뉴가 나옵니다. 독촉 메일을 보내거나, 본사가 대리로 새 기록을 씁니다.
3. 기간을 바꾸면 그 기간 기준으로 다시 그립니다.

## 요청 보내기

양식 제출을 따로 요청하거나 공지할 때 씁니다. 정기 양식은 요청을 보내지 않아도 마감이 잡히고, 트리거가 설치돼 있으면 자동으로 독촉됩니다.

1. 배포·요청 → 새 요청을 누릅니다.
2. 종류를 고릅니다. 양식 요청은 기록을 받고, 공지는 읽었는지만 확인합니다.
3. 제목과 안내 문장을 씁니다.
4. 양식 요청이면 받을 양식과 기간을 고릅니다.
5. 대상 사업장을 고릅니다. 전체 또는 일부.
6. 마감일을 정합니다. 필요하면 첨부 파일을 올리고, 확인(열람) 필요 여부와 독촉을 정합니다.
7. 보내기를 누릅니다. 대상 사업장 담당자에게 메일이 갑니다.

보낸 뒤

1. 배포·요청 목록에서 요청마다 회수율 막대와 미회수 사업장을 봅니다.
2. 요청을 열어 미회수 사업장에 독촉을 보냅니다.
3. 다 받았으면 마감합니다. 잘못 보냈으면 취소합니다.

자동 독촉: 트리거가 설치돼 있으면 마감 3일 전·1일 전과 기한경과 때 매일 아침 독촉 메일이 자동으로 갑니다(설정에서 바꿈).

## 검토(확인·반려)

1. 검토함을 엽니다. 왼쪽은 제출 대기 목록, 오른쪽은 고른 기록의 미리보기입니다.
2. 왼쪽에서 기록을 고릅니다. 오른쪽에서 요약·입력 내용·사진·서명·연결 조치를 봅니다.
3. 문제가 없으면 **확인**을 누릅니다. 확인된 기록은 잠깁니다.
4. 고칠 것이 있으면 **반려**를 누르고 사유를 씁니다. 사업장 담당자에게 메일이 가고, 사업장 홈에 반려 기록으로 뜹니다.
5. 사업장이 고쳐 다시 내면 검토함에 다시 올라옵니다.

- 단계가 있는 양식(재해·사고, 작업중지 등)은 단계마다 들어옵니다. 재해·사고와 작업중지는 단계 보고가 들어오면 본사 메일로 바로 알림이 갑니다.
- 확인한 기록을 다시 열어야 하면 관리자가 기록 상세에서 **확인 취소**를 누릅니다. 상태가 제출로 돌아갑니다.

## 조치대장

점검·평가·보고에서 나온 개선 조치를 끝까지 관리합니다.

조치는 이렇게 생깁니다.

- 일일점검·체크리스트의 주의·불량 항목, 위험성평가의 높음·보통 위험, 사고 재발방지 대책 등이 제출될 때 자동 등록됩니다.
- 본사가 조치대장에서 직접 등록할 수도 있습니다.

상태 흐름: **등록 → 조치중 → 완료 → 확인**. 그 밖에 **보류**, **고객사 이관**(고객사 설비·권한 문제로 고객사에 넘긴 것).
위험도는 높음·보통·낮음이고, 기한 기본값은 높음 1일·보통 7일·낮음 30일입니다.

1. 조치대장을 엽니다. 기한순으로 정렬돼 있고, 기한경과 조치는 따로 표시됩니다.
2. 위 필터로 사업장·상태·위험도·기한을 좁힙니다.
3. 조치를 눌러 상세를 엽니다. 출처 기록, 조치 전·후 사진, 이력을 봅니다.
4. 사업장이 완료를 보고하면 조치 후 사진을 보고 **확인**합니다.
5. 기한·담당자를 바꾸거나 보류·고객사 이관으로 돌릴 때는 사유를 남깁니다. 이력에 쌓입니다.

## 분석 화면 읽는 법

1. 위 필터 바에서 기간과 사업장을 고릅니다. 모든 분석 화면이 같은 필터를 씁니다.
2. 제목 아래 회색 문장과 발견 문장 목록을 먼저 읽습니다. 데이터에서 규칙으로 찾은 사실이고, 누르면 근거 화면으로 갑니다.
3. 숫자 줄 → 차트 → 표 순서로 내려가며 확인합니다.

| 화면 | 보는 것 |
|---|---|
| 개요 | 월별 사고·아차 추이와 핵심 숫자 |
| 재해·아차 | 재해·아차사고·작업중지·수칙위반의 유형·원인·추이 |
| 위험성평가 | 위험 수준 분포, 감소대책 진행 |
| 일일점검 | 제출률, 주의·불량이 잦은 항목과 사업장 |
| 교육·훈련 | 안전보건교육·비상훈련 실시와 참석 |
| 조치 이행 | 기한 내 완료율, 기한경과 분포 |
| HEC 준비도 | 고객사(HEC) 평가 항목별 준비 상태와 모의점수 |
| 사업장 비교 | 사업장별 스코어카드 |
| 양식별 분석 | 양식 하나의 선택·숫자 항목 분포와 추이 |

- 차트는 한 차트에 한 색을 씁니다. 진한 색이 주 데이터, 회색이 비교 대상입니다.
- 0은 0으로, 값이 없으면 회색 대시(—)로 표시합니다.
- HEC 모의점수는 분기 점검(N4) 결과로 계산한 추정치입니다. 고객사 공식 점수가 아닙니다.
- AI 요약 버튼은 관리자가 키를 넣었을 때만 보입니다. 요약 숫자만 보내 문단을 받습니다.
- 분석 보고서 인쇄로 지금 보고 있는 범위의 분석을 종이·PDF 로 뽑습니다.

## 엑셀·시트 내보내기

1. 기록 조회를 엽니다.
2. 기간·사업장·양식·상태 필터로 범위를 좁힙니다.
3. 내보내기를 누르고 대상(기록·조치·양식별)과 형식을 고릅니다.
   - **엑셀**: `.xlsx` 파일을 내려받습니다.
   - **구글 시트**: 드라이브에 새 구글 시트를 만들고 링크를 엽니다.
4. 양식 하나를 고르면 그 양식의 항목이 열로 펼쳐집니다.

범위가 너무 크면 6분 실행 한도에 걸릴 수 있습니다. 기간을 나눠서 내보냅니다.

## 인쇄

1. 기록 하나: 기록 상세 → 인쇄. A4 공문 양식(HDS 워드마크·문서번호·결재란)으로 나옵니다.
2. 여러 건: 기록 조회에서 기록을 골라 일괄 인쇄.
3. 빈 양식: 양식 화면에서 양식을 골라 빈 양식 인쇄. 종이로 먼저 받을 때 씁니다.
4. 브라우저 인쇄 창에서 용지 A4 를 고릅니다. 대상에서 "PDF로 저장"을 고르면 PDF 파일이 됩니다.

## 사업장 관리(관리자)

1. 사업장 → 새 사업장에서 ID·이름·담당자 이메일 등을 넣고 저장합니다. 링크가 자동으로 만들어집니다.
2. 사업장 상세에서 링크 복사 또는 QR 내려받기 → 담당자에게 개별 전달합니다.
3. PIN 을 정하면 링크와 PIN 이 모두 있어야 들어옵니다.
4. 링크가 새었거나 담당자가 바뀌면 링크 재발급 후 새 링크를 전달합니다. 예전 링크는 더 이상 쓸 수 없습니다.
5. 필수 양식을 사업장에 맞게 고칩니다. 비우면 설정의 기본값을 씁니다.

# 사업장 담당자용

## 링크로 들어가기

1. 본사가 보낸 사업장 링크를 누르거나 QR 을 휴대폰 카메라로 찍습니다.
2. 화면에 나온 사업장 이름이 우리 사업장인지 확인합니다.
3. **작성자 이름**을 넣습니다. 기록에 작성자로 남습니다.
4. 본사가 PIN 을 정했다면 PIN 도 넣습니다. 5번 틀리면 15분 동안 잠깁니다.
5. 시작을 누릅니다. 같은 휴대폰에서는 30일 동안 다시 묻지 않습니다.

- 브라우저 메뉴의 "홈 화면에 추가"를 하면 앱처럼 바로 열 수 있습니다.
- 사업장 링크는 비밀번호와 같습니다. 다른 사람에게 넘기지 마십시오. 잃어버렸으면 본사에 다시 요청합니다.
- 작성자가 바뀌면 로그아웃 후 새 이름으로 들어옵니다.

## 오늘 할 일

홈 화면이 "오늘 무엇을 내야 하나"를 마감순으로 보여 줍니다.

1. **받은 요청**: 본사가 보낸 요청·공지. 눌러서 읽고, 양식이 있으면 바로 작성합니다.
2. **정기 마감**: 일일점검·월간보고·분기·반기 양식 중 아직 안 낸 것.
3. **반려된 기록**: 본사가 돌려보낸 기록. 가장 먼저 고칩니다.
4. **내 미결 조치**: 아직 끝나지 않은 우리 사업장 조치.

아래 큰 버튼 두 개: **오늘 일일점검**, **사고·아차 보고**.

언제까지 내나(기본 마감)

| 양식 | 마감 |
|---|---|
| 일일 안전보건 점검 | 근무 다음 날 10:00(야간조는 근무 시작일 기준) |
| 월간 안전보건현황 보고 | 다음 달 5일 |
| 보호구·장비 분기 실사, 분기 사업장 점검 | 분기 끝 + 10일(1·4·7·10월 10일) |
| 안전보건교육, 비상대응훈련 | 반기 끝 + 7일(7월 7일·1월 7일) |
| 작업중지권 반기 이행점검 | 반기 끝 + 10일(7월 10일·1월 10일) |
| 하절기 폭염 대응 점검 | 4~9월 매월 말일 |
| 위험성평가 | 직전 평가일 + 1년 |

본사가 요청에 따로 마감을 정했으면 그 날짜가 먼저입니다.

## 일일점검 쓰기

1. 홈에서 **오늘 일일점검**을 누릅니다.
2. 날짜와 근무조를 확인합니다.
3. 인원·건강, 날씨·체감온도를 넣습니다.
4. 점검 항목으로 내려갑니다. 모두 실제로 확인했으면 **전부 양호**를 누르고, 다른 항목만 고칩니다.
5. 항목마다 양호·주의·불량·해당없음 중 하나를 누릅니다.
6. 주의·불량이면 비고를 쓰고 사진을 붙입니다. 제출하면 조치대장에 자동으로 등록됩니다.
7. 서명합니다.
8. **제출**을 누릅니다. 빠진 항목이 있으면 위에 목록이 뜨고 해당 칸이 빨갛게 표시됩니다.

- 입력하고 3초가 지나면 자동으로 임시저장됩니다. 화면을 닫아도 작성중으로 남습니다.
- 통신이 끊기면 저장되지 않을 수 있습니다. 저장 표시를 확인합니다.

## 사고·아차 보고

사람이 다쳤거나 다칠 뻔했으면 **먼저 전화로 소장과 본사에 알립니다.** 앱 입력은 그다음입니다.

1. 홈에서 **사고·아차 보고**를 누릅니다.
2. 알맞은 양식을 고릅니다.

   | 상황 | 양식 |
   |---|---|
   | 재해, 무상해 사고, 중대 아차사고 | 재해·사고 보고서 |
   | 아차사고, 위험요인, 개선 제안, 근로자 의견 | 열린안전소통센터 보고서 |
   | 급박한 위험으로 작업을 멈추고 대피함, 고객 폭언·폭행으로 업무를 중단함 | 작업중지권 행사 보고서 |
   | 안전수칙 위반(고객사 지적·자체 적발) | 안전수칙 위반 보고서 |

3. 첫 단계만 채워 바로 냅니다. 나머지 단계는 나중에 같은 기록을 열어 이어서 씁니다.

재해·사고 보고서 단계와 기한

| 단계 | 기한 |
|---|---|
| 1. 속보 | 24시간 이내 |
| 2. 조사·원인 | 3일 이내 |
| 3. 재발방지 대책 | 7일 이내. 대책은 조치대장에 자동 등록 |
| 4. 종결 | 경과를 수시로 더한 뒤 종결 |

- 단계마다 **제출**을 누릅니다. 첫 단계만 내도 본사에 "1단계 보고"로 바로 보이고, 본사 메일로 알림이 갑니다.
- 작업중지권 행사 보고서는 즉시보고 → 조치·재개 → 사후관리 → 30일 뒤 불리한 처우 확인 순서입니다. 사후관리부터는 본사가 씁니다.

## 사진·서명

사진

1. 사진 칸의 카메라 버튼을 누릅니다.
2. 바로 찍거나 앨범에서 고릅니다.
3. 사진은 자동으로 줄여서 올라갑니다. 한 파일 8MB 까지입니다.
4. 처음이면 브라우저가 카메라·사진 접근을 묻습니다. 허용합니다.

서명

1. 서명 칸을 누르면 서명판이 열립니다.
2. 손가락으로 서명하고 저장합니다. 잘못 썼으면 지우고 다시 씁니다.
3. 여러 명이 종이에 서명했으면 "종이 서명지 별첨"을 고르고 서명지를 사진으로 붙입니다.

## 반려 고치기

1. 홈의 **반려된 기록**에서 기록을 엽니다.
2. 맨 위 반려 사유를 읽습니다.
3. 사유대로 고칩니다.
4. **제출**을 누릅니다. 본사 검토함에 다시 올라갑니다.

본사가 확인한 기록은 잠겨서 고칠 수 없습니다. 꼭 고쳐야 하면 본사에 요청합니다.

## 조치 완료 보고

1. 홈의 **내 미결 조치** 또는 조치 화면을 엽니다.
2. 조치를 누릅니다. 무엇을 언제까지 해야 하는지 확인합니다.
3. 조치를 시작하면 **조치중**으로 바꿉니다.
4. 끝나면 **완료**를 누르고, 조치 후 사진과 한 줄 메모를 남깁니다.
5. 본사가 확인하면 **확인**으로 바뀌고 끝납니다.

기한 안에 못 끝내면 사유를 메모로 남기고 본사에 알립니다.

## 받은 요청·공지

1. 받은 요청 화면을 엽니다.
2. 요청·공지를 누르면 읽음으로 표시됩니다. 본사에서 누가 언제 읽었는지 봅니다.
3. 첨부 파일은 눌러서 내려받습니다.
4. 양식 요청이면 작성 버튼으로 바로 씁니다.

## 인원 명부

1. 사업장 정보 화면을 엽니다.
2. 인원을 추가·수정합니다. 이름·직무·역할·전화 끝 4자리만 넣습니다.
3. 그만둔 사람은 지웁니다. 지난 기록의 이름은 그대로 남습니다.

명부에 있는 사람은 양식의 참석자·점검자·서명자 칸에서 골라 쓸 수 있습니다.
